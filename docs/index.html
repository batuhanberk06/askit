How it works

Three ways in. One review before Send.

AskIt does not run its own AI and does not submit messages automatically. Choose a source, select an AI and task, then review the prepared content on that provider's website.

01 · SELECT

Selected text

Select text on a page and start AskIt from the context menu.

02 · CAPTURE

Visible screenshot

Capture the visible tab from the popup or with Alt+Shift+S. Manual copy or drag is available when attachment fails.

03 · LINK

Current page URL

Share only the page URL with the AI. AskIt does not read or upload the page HTML.

Your choice

Use the AI web app you already know.

Choose Summarize, Translate, Explain, Fact-check, Extract information, or write your own question. Provider accounts and data handling are governed by each provider.

Privacy by scope

No AskIt server. No analytics.

Pending content stays in browser session storage until it is prepared, expires, is cleared, or the browser session ends. When you continue, the content is transferred directly into the AI website you selected.
