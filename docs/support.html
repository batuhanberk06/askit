Help and troubleshooting

AskIt Support

GitHub issues are public. Never attach private text, screenshots, credentials, session details, or personal information.

Before opening an issue

  1. Confirm that Chrome is version 127 or newer.
  2. Reload AskIt from chrome://extensions.
  3. Confirm that the selected AI website opens normally and complete any required sign-in.
  4. Try the same action once more on a regular HTTPS page.

What to include

  • AskIt version from chrome://extensions;
  • Chrome version and operating system;
  • selected AI provider;
  • input type: selected text, page URL, or screenshot;
  • selected AskIt task;
  • the exact error message, after removing sensitive content; and
  • clear reproduction steps using harmless sample content.
Open an issue View existing issues

Known limitations

  • AskIt cannot capture or share restricted browser pages such as chrome:// pages.
  • AI providers can change their composer interfaces, which may temporarily break text or image insertion.
  • Screenshot attachment is not guaranteed. AskIt offers a copy/drag fallback when it detects a failed attachment.
  • The AI provider may require an account, sign-in, or acceptance of its own terms.
